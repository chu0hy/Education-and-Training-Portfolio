  # CS50 Scratch Project (v1.4)

## Overview
This project is an interactive Scratch game developed as part of Harvard CS50x.

## Features
- Player-controlled satellite
- Hazard avoidance (asteroids, enemy satellite)
- Collectibles (Cheesy Puffs)
- Score tracking
- Game state logic (GameOver system)

## Lessons Learned
- Event-driven programming
- State management
- Collision handling
- Basic system design
